# Invoice Management Dashboard (Invoice List)

## Description

As a Franchisee, I need access to all the family invoices (at the payor level) in one location so that I can manage the invoices efficiently from a central location and improve my overall financial standing. 

## Acceptance Critera

1. The solution shall provide a "Invoice Management" dashboard in FMS to host a consolidated view of invoices and payment status. 
2. Provide the ability to filter/group invoice by one of the following parameters: None (default), Family, Current Enrollment Status.
3. Provide the ability to filter/group invoice using an alphanumeric text search on the following parameters;  Invoice Number, Payor (name), Family (name)
4. Display the following columns for invoice results: Invoice Number, Amount, Payor, Payor Email, Family, Children,  Enrollment Status, Notes, Actions  
          4.1 Under the Children column , each invoice shall provide a clear child level breakdown per payor. For example if an invoice is $1000, it should clearly display breakdown per child for example $700 for child 1 and $300 for child 2 (per their individual contract charges) 
          4.2 The following actions shall be available as options for users when they click on the hamburger menu: TBD 

                  4.2.1 Resend invoice
                  4.2.2 Resend invoice receipt
                  4.2.3 TBD 

5. The solution shall provide users with the ability to select one ore multiple invoices from the dashboard using a check-box selection. 
   5.1 . Provide users with the ability to perform the actions listed under 4.2 for multiple invoices in one step. 
     

Implement using AG Grid to support fast filtering, sorting, paging, and export for finance workflows
