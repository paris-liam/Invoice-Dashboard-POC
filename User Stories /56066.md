# Invoice Management Dashboard (Header Section)

## Description 

As a Franchisee, I need clear and concise view to my financial metrics directly via the finance dashboard so that I can manage my overall financials better.  

## Acceptance Criteria 

1. The solution display the following information on the header of the new dashboard. 
    1.1. Display the Total Outstanding A/R (Accounts Receivables) for the franchisee on the top left corner. 
    1.2  Display the count of "Open Invoices" next to Total Outstanding A/R
    1.3  Display the count of "Past Due Invoices" next to Open Invoices
    1.4  Display the count of invoices "Due this week" next to Past Due Invoices
    1.5  Display the count of invoices "ACH Failures" next to Due this week 

2. The solution display the Invoice count by status under "Invoice Status" section below the header widgets.  
   2.1 Display the count by invoice status: Draft, Approved, Sent, Paid, Past Due, Failed
   2.2 Display the count using a pie chart graphical representation (as shown in prototype) 
   2.3 Display the Aging Analysis for outstanding (open) invoices only. 
   2.4 Display the count using a horizontal bars graphical representation. (as shown in prototype) 

3. The solution display the "Approval Queue" below the charts:
    3.1  Display the count by invoices in Draft status 
    3.2  Display the count by invoices in Approved status
